# NostrCraft repository instructions

## Changelog scope

When writing, reviewing, or comparing `CHANGELOG.md`, include only changes that affect the Minecraft mod itself: gameplay, in-game behavior, features, UI, assets, recipes, localization, or other mod content

Compare the current work against the previous release tag and inspect the changed game files. Exclude development and repository maintenance changes, including build configuration, Gradle wrapper files, CI/release workflows, documentation, and other tooling, even when those changes are part of the same release period
